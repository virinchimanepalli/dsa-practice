# JS Practice

Plain Node.js (v18+), no dependencies.

## Run a file
    node dsa/01-arrays/two-sum.js

## Re-run on every save
    node --watch dsa/01-arrays/two-sum.js

## New question
1. Copy `_template.js` into the right topic folder.
2. Write the solution, add `test(...)` lines, run it.

`test(name, actual, expected)` deep-compares the values and prints ✅ or ❌.

## Folders
- `dsa/`: data structures & algorithms, by topic
- `frontend/`: JS interview topics (closures, promises, polyfills, etc.)
